# Estudos de Lógica de Programação e POO em Python 🐍

Este repositório reúne projetos, atividades e algoritmos desenvolvidos durante a matéria de Lógica de Programação. O foco é a prática dos fundamentos da linguagem Python, incluindo estruturas condicionais, laços de repetição e vetores, além da aplicação de conceitos de Programação Orientada a Objetos (POO).
